# 🪖 Weight of Tactics: Road to Mudscow

**Weight of Tactics** is a Proof of Concept (PoC) for a 2D top-down tank combat game. This project was created as a practical learning exercise in **Godot Engine**, aiming to modernize the classic gameplay mechanics of the legendary NES *Battle City*, while introducing a dark, tactical, and realistic atmosphere set in Eastern Europe.

Since this project focuses purely on learning with a short and well-defined scope, the game features **a single playable level** designed to test the core gameplay loop.

---

## 🚀 Key Features in development:

*   **Modernized Top-Down Style:** Arcade-style gameplay inspired by 8-bit classics, but upgraded with a modern visual style and user interface.
*   **2-Player Local Multiplayer:** Built specifically for shared-screen local co-op play.
*   **Eastern European Setting:** Military aesthetic featuring cold tones, mud, and rain.
*   **Short Scope (Proof of Concept):** A single compact map focused on polishing tank movement, collision handling, and shooting mechanics.

---

## 🛠️ Tech Stack

*   **Game Engine:** Godot Engine (GDScript)
*   **Perspective:** 2D Top-Down
*   **Platform:** PC

---

## 🎮 Controls (Local)

The game is configured to be played on a single keyboard or using a keyboard and controller setup:

| Action | Player 1 (Keyboard) | Player 2 (Keyboard / Controller) |
| :--- | :--- | :--- |
| **Movement** | `W` `A` `S` `D` | Arrow Keys / D-Pad |
| **Shoot** | `Spacebar` | `Enter` / Button A |
| **Pause Menu** | `Esc` | `Start` or `Esc` |

---

## ⚙️ How to Run the Project

To test the prototype or review the source code in Godot:

1. Clone this repository:
2. Download and install **Godot Engine** (version 4.7.1 recommended).
3. Open Godot, click **Import**, and locate the `project.godot` file inside the cloned folder.
4. Press `F5` to run the main menu scene.
